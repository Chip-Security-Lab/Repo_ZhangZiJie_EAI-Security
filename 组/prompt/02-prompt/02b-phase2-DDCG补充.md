## 任务

获取 DDCG（NeurIPS 2025）的**完整全文**并深度分析。现有分析中缺失的关键细节：

### 必须搞清楚的问题

1. **C_F 的训练数据具体是什么？** VirtualHome 和 ScienceWorld 中的什么信号被用作「不可行」的 ground truth label？是仿真引擎返回的错误码、人工标注、还是自动规则？

2. **C_F 的架构细节**：RoBERTa-base 的输入格式是什么？（`[CLS] 动作描述 + 状态描述 [SEP]`？还是有更结构化的输入？）输入中是否包含任何数值物理参数？

3. **C_F 的失败模式**：论文报告了 C_F 的 false positive（判为可行但实际不可行）和 false negative（判为不可行但实际可行）吗？具体数据？

4. **与 LLM 的部署关系**：C_F 和 GPT-4 在同一个 Python 进程中运行，还是独立进程？论文是否讨论了如果 LLM（GPT-4）被攻陷，C_F 是否还能独立运作？

5. **CMDP 形式化的具体约束**：安全动作集 A_safe 在论文中是如何具体定义的？是通过 C_F 的阈值、还是独立的规则集？

6. **长时域场景的具体数据**：报告中提到 DDCG "特别优势在长时域"，具体的任务长度、成功率数据是什么？C_F 在长时域是否会累积错误？

7. **论文自述的局限**：Limitations / Future Work 部分说了什么？
