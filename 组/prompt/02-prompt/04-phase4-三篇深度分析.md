## 论文 2：ConceptAgent

**文件**：`ConceptAgent.pdf`

### 2.1 解决什么问题

- 这篇论文要解决的具体问题是什么？
- 它针对的是 LLM 规划器的哪种失败模式？
- 作者观察到什么现象促使他们做这个工作？

### 2.2 怎么解决的（详细流程，要能让导师听懂）

请按以下步骤详细描述 ConceptAgent 的工作流程：

**整体架构**：画一个文字流程图——从"人给指令"到"机器人执行动作"，ConceptAgent 插在哪一步？

**步骤一：LLM 生成计划和前置条件**
- 给 LLM 什么输入？
- LLM 输出什么？（动作序列 + 每个动作的前置条件）
- 前置条件是什么形式？（PDDL 风格？布尔谓词？举例说明）
- 17 个谓词分别是什么类型？举几个典型的

**步骤二：3D 场景图怎么建**
- 场景图是什么——用通俗语言解释
- 怎么从相机图像变成场景图？（SAM + CLIP 做什么）
- 场景图里包含什么信息？不包含什么信息？

**步骤三：前置条件检查**
- 针对每个动作，怎么检查它的前置条件在场景图里是否成立？
- 检查通过 → 做什么？检查不通过 → 做什么？
- 反馈给 LLM 重新规划的过程是怎样的？

**步骤四：MCTS 规划优化**
- 为什么还需要 MCTS？LLM 不是已经输出计划了吗？
- LLM 评判（critic）怎么打分？

**关键数据**：
- 前置条件准确率/召回率
- 仿真和真实机器人上的成功率
- 哪儿表现好、哪儿表现差

### 2.3 有什么缺陷（逐条列出，每条一句话定性 + 一段解释）

至少分析以下几条，如果原文还有更多请补充：

**缺陷 1：LLM 既当运动员又当裁判**
- LLM 生成计划，同一个 LLM 生成这个计划的前置条件
- 如果 LLM 出错（或被越狱），它可以生成一套"自洽但危险"的计划+前提组合
- 为什么这是一个根本性的安全设计缺陷？

**缺陷 2：17 个固定布尔谓词——不可扩展**
- 谁定义这 17 个谓词？能覆盖多少场景？
- 换一个任务/环境，需要重新定义吗？
- 为什么"杯子耐温 80°C"这种连续物理约束在布尔谓词系统中无法表达？

**缺陷 3：状态来自场景图——信息缺失时悄悄出错**
- 场景图能提供什么信息？不能提供什么？
- 如果一个物体的重要属性不在场景图里（如重量、温度、材质），系统会怎么办？
- 场景图缺失时，系统是"知道自己不知道"还是"以为自己知道"？

**缺陷 4：真实成功率很低**
- 为什么步级准确率看起来还行（~73-100%），但整体任务成功率只有 20-40%？
- 每一步的感知错误累积意味着什么？

## 论文 3：SAFER

**文件**：`Safety Aware Task Planning via Large Language Models in Robotics.pdf`

### 3.1 解决什么问题

- 这篇论文要解决什么问题？
- LLM 做任务规划时为什么自然倾向于忽略安全？
- 作者用什么方式证明这个倾向存在？

### 3.2 怎么解决的（详细流程）

**整体架构**：Task LLM 和 Safety LLM 怎么分工？CBF 在哪一层？用文字画清楚三层关系。

**模块一：Task Planning LLM**
- 输入什么？输出什么？
- 它只管效率，不管安全——具体表现是什么？

**模块二：Safety Planning LLM**
- 它审查什么？15 个风险标准是什么？举 3-4 个典型例子
- 它怎么给 Task LLM 反馈？反馈长什么样？
- 迭代过程怎么进行？

**模块三：CBF 控制层**
- CBF 是什么——用最通俗的语言解释
- 它在执行时做了什么约束？和 Task/Safety LLM 的关系是什么？
- **关键问题**：真正的安全保证来自 CBF 还是 Safety LLM？为什么？

**关键数据**：
- 安全违规减少了多少？
- GPT-4o 和 DeepSeek-r1 的对比说明了什么？

### 3.3 有什么缺陷

**缺陷 1：Safety LLM 也是 LLM——"LLM 审查 LLM"的根本问题**
- Safety LLM 会不会被越狱？论文讨论过吗？
- 如果 Task LLM 和 Safety LLM 共享同一个基础模型（如 GPT-4o），它们有共同的盲区吗？
- 这意味着什么？

**缺陷 2：真正的安全保证不来自 LLM**
- CBF 做的是什么？运动学约束（避障、关节限制）
- CBF 能检查"杯子能不能装开水"吗？能检查"地面够不够摩擦力"吗？
- LLM 层的安全判断和 CBF 层的物理约束之间有什么断层？

**缺陷 3：需要外部追踪系统**
- Vicon 是什么？为什么真实家庭部署中不可能有？
